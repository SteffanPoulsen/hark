kuulo update test for Windows

On Windows, double-click run-test.cmd in this folder and follow what it says.
It installs kuulo 0.0.1 (a test build), updates it to 0.0.2 twice, and offers to
uninstall it at the end. Everything it sees, and your answers, go to a
report-<time>.txt in this folder. Back in Linux, tell Claude the test is done.
